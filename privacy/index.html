Field Guide Sync

This page covers how Field Guide Sync — a personal, single-user tool built on top of this Field Guide — uses the Pinterest API.

Last updated 29 Aug 2026 · applies to this app’s use of the Pinterest API only

What this is

Field Guide Sync is a personal, single-user tool. It is not a public product, is not distributed to other users, and exists only so its owner can read and organize their own Pinterest boards and pins for personal design research — the same research this Field Guide is built from.

What it accesses

Using Pinterest’s official API and the owner’s own authorization, this app can:

  • Read the owner’s own boards, pins, and basic profile information.
  • Create new boards and pins under the owner’s own account.

It does not access any other Pinterest user’s account, boards, or private data.

What it does with that data

Data pulled from the API is used only to organize the owner’s own saved pins into reference categories — the groups and log you see on this site — and, where requested, to create new boards from that organization. Nothing is sold, shared with third parties, used for advertising, or made available to anyone other than the account owner.

Data retention & deletion

Access can be revoked at any time from Pinterest account settings under Apps. Revoking access immediately ends this app’s ability to read or write any further data.
